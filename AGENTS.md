# FolioVault HTML

This repository is the HTML edition only. Do not add the desktop Linux app.
Edit src/foliovault.html; dist/ is generated. No external runtime dependencies.
No plan/credential browser storage, network APIs, telemetry or plaintext export.
HTML networking and Bluetooth signals are warnings only, not environment gates.
Keep the guide-only scope: no wallet seeds/private keys/xpubs or signing.
Preserve VAULTFOLIO/1 crypto compatibility; v2/hardware unlock stays unsupported.
Fresh random encryption salts/nonces are required; they are not wallet entropy.
Retain all licenses and provenance. Never claim browser-memory erasure guarantees.
Use invented fixture data. Run npm run build, npm test, npm run verify.
Report browser acceptance/residue tests separately from Node tests.
Changes go through reviewed PRs. No force-push, rebasing, deletion or automatic
merging. Do not publish an upstream EntropyLab change or deploy a website here.
